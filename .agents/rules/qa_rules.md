# Правила работы агента (Faktura.uz QA)

## 1. Разделение обязанностей и папок в `.agents/`
Вся конфигурация и инструменты агента строго разделены по 5 подпапкам:
- **`.agents/rules/`**: Все правила, регламенты и инструкции поведения агента.
- **`.agents/script/`**: Все исполняемые скрипты автоматизации (Python, PowerShell, Bash). Любой новый скрипт добавляется ТОЛЬКО сюда.
- **`.agents/skills/`**: Все навыки (skills) для агента. Любой новый навык добавляется ТОЛЬКО сюда.
- **`.agents/mcp/`**: Конфигурации и манифесты всех MCP-серверов (`mcp_config.json` и др.).
- **`.agents/config/`**: Все конфигурационные файлы, токены, ключи и настройки подключения (`jira_config.json` и др.).

---

## 2. Правило хранения артефактов и задач
- Главная директория: `C:\Users\Acer\Desktop\FACTURA.uz`.
- Все задачи хранятся в `TASK/<KEY>/` (или `TASK/<DD.MM.YYYY> <KEY>/`).
- Запрещено сохранять рабочие файлы Faktura.uz вне этой папки.

---

## 3. Обязательная структура каждой задачи в `TASK/`
Каждая задача должна содержать:
1. **`IMG/`**: Для скриншотов с доски Jira, снимков багов, превью.
2. **`FILE/`**: Для документов (`.pdf`, `.xlsx`, `.docx`, `.csv`, шаблонов).
3. **`JSON/`**: Для тестовых JSON документов и контрактов.
4. **`TEST-INFO.txt`**: Текст задачи из Jira, требования, критерии приёмки, список скачанных файлов.
5. **`TEST-CASE.txt`**: Полный набор тест-кейсов (A: Позитивные, B: Граничные и негативные, C: Роли и права, D: Регрессия).
6. **`issue.json`**: Исходный JSON задачи из Jira REST API.

---

## 4. Интеграция с Jira
- **URL**: `https://jira.faktura.uz`
- **Конфигурация**: `.agents/config/jira_config.json`.
- **MCP-сервер**: `.agents/mcp/mcp_config.json`.
- **Скрипт подготовки задачи**: `.agents/script/prepare_task.py <KEY>`.
- При получении номера задачи агент автоматически запускает скрипт подготовки, скачивает все вложения и формирует `TEST-INFO.txt` и `TEST-CASE.txt`.
