## 2. Архитектура `.agents/`
Все расширения, конфигурации и инструменты агента строго разделены по 5 подпапкам:
- **`.agents/rules/`**: Все правила, регламенты и требования к поведению агента.
  - `qa_rules.md` — стандарты тестирования и хранения.
- **`.agents/script/`**: Исполняемые скрипты:
  - `prepare_task.py` — автоматизация выгрузки задачи из Jira, создания папок и скачивания файлов.
  - `jira_client.py` — CLI-клиент для Jira REST API.
- **`.agents/skills/`**: Навыки агента:
  - `qa-task-preparer/` — навык автоматической подготовки тестовой среды для задач Jira.
- **`.agents/mcp/`**: Все MCP-конфигурации:
  - `mcp_config.json` — конфигурация MCP-серверов (включая Jira MCP).
- **`.agents/config/`**: Все файлы конфигурации, ключи и токены:
  - `jira_config.json` — параметры подключения к Jira (`jira.faktura.uz`) и токен доступа.

---

## 3. Структура каждой задачи в `TASK/`
Каждая задача создается в формате `TASK/<KEY>/` (или `TASK/<DD.MM.YYYY> <KEY>/`):
- `IMG/` — скриншоты, превью, изображения багов.
- `FILE/` — документы (`.pdf`, `.xlsx`, `.docx`, `.csv`).
- `JSON/` — полезные нагрузки и контракты документов.
- `TEST-INFO.txt` — описание, требования, критерии приёмки и список вложений.
- `TEST-CASE.txt` — готовые тест-кейсы (A: Позитивные, B: Граничные/Негативные, C: Роли, D: Регрессия).
- `issue.json` — сырые данные задачи из Jira API.
