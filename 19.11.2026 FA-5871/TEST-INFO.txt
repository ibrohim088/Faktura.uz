Задача: Preview договора (роуминг) — показ наименования филиала только при наличии кода филиала

Описание проблемы
Для документов типа «Договор» (роуминг) preview отправителя и получателя строится без учёта кода филиала в подписываемом JSON. 
Некоторые договоры от других операторов роуминга приходят с наименованием филиала, но без кода филиала. 
Налоговая проверяет наличие кода филиала и при его отсутствии показывает договор без наименования филиала. 
У нас такие договоры отображаются с наименованием филиала, то есть иначе, чем в налоговой.

Что нужно реализовать
1. Для документа типа «Договор» (роуминг) при построении preview отправителя и получателя проверять в подписываемом JSON наличие кода филиала по каждой из сторон.
2. Если код филиала есть — показывать наименование филиала, как сейчас.
3. Если кода филиала нет — не показывать наименование филиала, даже если оно передано в подписываемом JSON.
4. Проверять отправителя и получателя отдельно, независимо друг от друга.

Область изменений
- Изменения касаются только документов типа «Договор» (роуминг).
- Отображение остальных типов документов не меняется.
- Подписываемый JSON не меняется. Меняется только отображение в preview.

Ожидаемый результат
Preview отправителя и получателя для договоров из роуминга совпадает с тем, как налоговая отображает данные о филиале: 
наименование филиала показывается только вместе с кодом филиала в подписываемом JSON.

Критерии приёмки
1. Договор (роуминг): в подписываемом JSON есть и код, и наименование филиала отправителя → в preview отправителя показывается наименование филиала.
2. Договор (роуминг): в подписываемом JSON есть наименование филиала отправителя, но нет кода филиала → в preview отправителя наименование филиала не показывается.
3. Пункты 1 и 2 так же выполняются для получателя.
4. Отправитель и получатель проверяются независимо: если код филиала есть только у одной стороны, наименование филиала показывается только у этой стороны.
5. Отображение preview для других типов документов не изменилось.
6. Подписываемый JSON договора не изменяется.
