mattpocock/skills - набор скилов для нормальной инженерии: уточнение плана, TDD, поиск багов, ревью

Caveman - режим коротких ответов без воды, экономит токены

Ponytail - режим "ленивого сеньора": агент пишет минимум кода и не усложняет

OpenSpec - сначала спека (план) в папке openspec/, потом код: propose, apply, archive

Spec Kit - набор от GitHub для разработки через спеку: принципы, спека, план, задачи, реализация

Cucumber (Given-When-Then) - формат сценариев "Дано, Когда, Тогда" для тест-кейсов и требований

setup-matt-pocock-skills - настройка набора скилов под проект, запускается один раз

ask-matt - подсказывает, какой скил или процесс подходит под твою задачу

grill-me - агент задаёт жёсткие вопросы по твоему плану, пока ты не начал писать не то

grill-with-docs - то же, но с опорой на документацию проекта

tdd - разработка через тесты: сначала тест, потом код

diagnosing-bugs - системный поиск причины бага

code-review - ревью изменений

triage - разбор и приоритизация задач и багов

wait-what - одно слово, чтобы остановить многословность агента

to-spec - превращает идею в спеку

implement-spec - реализует код по готовой спеке

to-tickets - разбивает работу на задачи

implement - реализация задачи

domain-modeling - моделирование предметной области проекта

codebase-design - проектирование структуры кода

improve-codebase-architecture - улучшение архитектуры существующего кода
