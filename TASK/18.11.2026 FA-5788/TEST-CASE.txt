Faktura.uz: проверка языка льготы (UI / API / Реестр)

Проверка в UI

1. Зайти в настройки и выбрать нужный язык (ru, oz, uz):
   - ru: русский
   - oz: узбекский (латиница)
   - uz: узбекский (кириллица)

2. После выбора обратить внимание на URL: языковой префикс после домена должен меняться в зависимости от выбранного языка:
   - ru: https://test.faktura.uz/ru/account/home
   - oz: https://test.faktura.uz/oz/account/home
   - uz: https://test.faktura.uz/uz/account/home

3. Зайти в документ и заполнить поля для льготы, чтобы проверить, на каком языке приходит название льготы.


Test-case 1 - UI
1. В настройках выбрал русский язык.
2. Зашёл в создание документа и ввёл ИКПУ-код, по которому есть льгота.
3. После ввода ИКПУ-кода название льготы пришло на русском языке, так как в настройках выбран русский язык.
4. Нажал «Создать документ»: документ создался, в preview льгота отображается на русском языке.
5. Открыл документ на редактирование.
6. Зашёл в настройки и выбрал узбекский (кириллица).
7. Перезагрузил страницу.
8. Открыл страницу с документом и нажал «Редактировать»: название льготы отображается на узбекском (кириллица).
9. Сохранил изменения.
10. Открыл preview: название льготы отображается на узбекском (кириллица).
11. Зашёл в настройки и выбрал узбекский (латиница).
12. Открыл документ и нажал «Редактировать»: название льготы отображается на узбекском (латиница).
13. Сохранил изменения.
14. Открыл preview: название льготы отображается на узбекском (латиница).


Test-case 2 - API
1. Для создания документа сначала зашёл в Postman и нашёл там подходящий документ.
2. Изменил JSON-данные этого документа и сформировал JSON, подходящий для создания документа:
   - передал ИКПУ-код, по которому есть льгота (ИКПУ-код: 10401999003000000);
   - в поле lgotaId передал id льготы, которая подходит для этого ИКПУ-кода (id льготы: 103277).
3. Нажал кнопку «Send»: в response вернулся id документа.
4. Скопировал этот id, перешёл в UI и открыл документ по этому id.
5. Посмотрел preview: название льготы приходит на языке по умолчанию (default lang = ru).
6. Отредактировал документ через UI: после редактирования название льготы приходит на языке системы (языке, выбранном в настройках).
7. Также в GetRoamingJSON при просмотре название льготы отображается на языке ru.


Test-case 3 - Реестр
1. Подготовил Excel-файл VatInvoice-WithLgot.xlsx: в колонке «Идентификационный код товара» указал ИКПУ-код, по которому есть льгота (ИКПУ-код: 10401999003000000).
2. В настройках, во вкладке «ИКПУ-коды», проверил, что для этого ИКПУ-кода есть льгота (id льготы: 103277).
3. В настройках выбрал узбекский (латиница).
4. Перешёл в «Документы» → «Импорт» → «Счет-фактура (ПКМ №489)»: тип счёта-фактуры «Стандартный», выбрал файл VatInvoice-WithLgot.xlsx и нажал «Импортировать».
5. Перешёл в реестр счёт-фактур: загруженный файл появился в списке со статусом «На проверке».
6. Открыл «Временные документы», выбрал созданный документ и нажал «Подтвердить»; в окне подтверждения тоже нажал «Подтвердить».
7. Открыл документ и посмотрел preview: название льготы отображается на языке по умолчанию (default lang = ru), хотя в настройках выбран узбекский (латиница).
8. Открыл документ на редактирование: название льготы отображается на узбекском (латиница), то есть на языке, выбранном в настройках.
9. Сохранил изменения.
10. Открыл preview: название льготы отображается на узбекском (латиница).
