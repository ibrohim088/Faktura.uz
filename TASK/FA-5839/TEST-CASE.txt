Сначала добавляем новый шаблон документа через панель администратора.

Экспорт в Excel: после нажатия на кнопку берётся общее количество документов, независимо от выбора. Нельзя выбрать один документ и экспортировать только его.
Для того чтобы получить экспорт в Excel только одного документа, надо сначала применить такой фильтр, чтобы после фильтрации остался только именно тот документ, который нужен, а остальных не было.
После того как мы применили уникальный фильтр, теперь можем сделать экспорт в Excel. После этого внутри Excel есть только один документ.

Если мы выберем checkbox внутри таблицы, то это не поможет, он просто не сработает. Для того чтобы он работал, разработчик исправляет код (13:57 09.11.2026).

Есть три метки: Contract, Invoice, Letter. Можно добавить больше через «Настройки» или вообще удалить их.
Для того чтобы назначить документу метку внутри вкладки, надо сначала выбрать документ, которому хотим
добавить метку. После этого нажимаем на кнопку с иконкой "book-marking". После нажатия откроется модальное
окно, внутри есть три метки. Выбираем одну и сохраняем.

Во всех вкладках внутри есть кнопка «Экспорт в Excel». После нажатия на кнопку скачивается файл Excel с документами, внутри есть поля.
Название файла: Documents_09112026.xlsx - Documents_ddmmyyyy.xlsx
dd - day, день
mm - month, месяц
yyyy - year, год
