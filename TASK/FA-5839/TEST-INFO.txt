======================================
ЭКСПОРТ В EXCEL: СТОЛБЕЦ «МЕТКИ»
======================================

ОПИСАНИЕ
--------
Пользователи назначают документам метки через действие «Отметить как».
В списке документов метка отображается под названием документа серой
плашкой (например, «TestDocs»). При выгрузке списка кнопкой
«Экспорт в Excel» метки в файл не попадают.

Клиент Hamkor bank использует метки для учёта документов по филиалам
и направлениям и не может работать с выгрузкой без них.


ШАГИ ВОСПРОИЗВЕДЕНИЯ
--------------------
1. Открыть «Документы» → «Все документы».
2. Выбрать один или несколько документов, нажать «Отметить как»
   и выбрать метку (например, TestDocs).
3. Убедиться, что метка отображается под названием документов в списке.
4. Нажать «Экспорт в Excel» внизу списка и открыть файл.


ФАКТИЧЕСКИЙ РЕЗУЛЬТАТ
---------------------
Файл Documents_ДДММГГГГ.xlsx (лист «Documents Report») содержит столбцы:
Дата договора, Контрагент, Общая сумма, ИНН, Создан, Обновлен, Реестр,
Статус, Комментарий, Ошибка.
Столбца с метками нет.

Дополнительно: в столбце «Дата договора» даты выгружаются в разном
формате — «23.10.2026» и «2026/10/22».


НЕОБХОДИМО РЕАЛИЗОВАТЬ
----------------------
1. Столбец «Метки»:
   - Добавить в файл экспорта столбец «Метки» после столбца «Статус».
   - Несколько меток одного документа перечислять через запятую
     в одной ячейке.
   - Документ без меток — пустая ячейка.

2. Охват экспорта:
   - Столбец выгружается из всех разделов списка документов:
     Входящие, Исходящие, Черновики, Отказанные, Удалённые, Архив,
     Аннулированные, Все документы.
   - Выгрузка учитывает фильтры, применённые в списке, в том числе
     фильтры «Метка» и «Без метки».

TEST-CASE
======================================

ПРЕДУСЛОВИЕ: СОЗДАНИЕ МЕТКИ
---------------------------
1. Перейти в «Настройки» → «Метки».
2. Нажать «Добавить», ввести название метки и сохранить.

НАЗНАЧЕНИЕ МЕТКИ ДОКУМЕНТУ
--------------------------
1. Перейти в «Документы» → «Все документы».
2. Выбрать один или несколько документов.
3. Нажать «Отметить как» (иконка закладки).
4. В открывшемся модальном окне выбрать созданную метку из списка.
5. Убедиться, что метка отображается под названием документа в списке.

ЭКСПОРТ В EXCEL
---------------
При нажатии «Экспорт в Excel» скачивается файл Documents_06112026.xlsx.
Столбец «Метки» добавлен после столбца «Статус».
