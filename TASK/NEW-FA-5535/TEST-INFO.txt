

1. Реестр оркали юклаш:
    Реестр колонкалар: 
        Получатель: ИНН, Название, Адрес
    
    Форма элементлари: 
        Email, 
        Вебсайт, 
        Логотип, 
        Должность, 
        Содержимое HTML, 
        Прикрепление: 
            файллар

Ответ Результат проверки:
    ВНУТРИ ШАБЛОНА EXCEL ЕСТЬ ЭТИ ПОЛЯ:
        Инн контрагента:
            Номер
            Дата
            Контрагент
            Адрес контрагента
            ИНН контрагента
    
    Внутри формы ввода есть эти поля - ЕСТЬ ФОТО:
        Реестр получателей (Excel) - суда зогружаем файл с контрагентом
        Контактные данные отправителя:
            Эл.адрес,
            Website,
            Логотип - есть предупреждение для Логотип: изображение от 100×100 до 512×512 пикселей, не более 512 КБ (PNG, JPEG, GIF, BMP или TIFF).,
            Телефон - есть особые форматы (Допустимые форматы: ( +998 xx) xxx-xx-xx, +998 (xx) xxx-xx-xx, +998xxxxxxxxx, +998 xx xxx-xx-xx ) также есть и преду преждени если ввести неверные формат номера (Номер телефона не соответствует допустимым форматам (998770886505). Допустимые форматы: (+998 xx) xxx-xx-xx, +998 (xx) xxx-xx-xx, +998xxxxxxxxx, +998 xx xxx-xx-xx)
    
    Подписант:
        ПИНФЛ - поля принимает только ПИНФЛ
        ФИО - если ввести ПИНФЛ то он автоматом подтянит ФИО
        Должностъ - вручную надо прописать

    Содержимое письма:
        Содержимое HTML - обычные textarea которые тнянится только вниз
    
    Прикрепление - есть описание (Можно добавить до 10 файлов, размер файла не должен превышать 2mb), если передать файл которые превышет огроничение то внизу над кнопкой Импортировать он подсвечится красным, можна добавит только 10 файло больше нельза так как после добовление 10 того файла кнопка выбор файла станет disable
