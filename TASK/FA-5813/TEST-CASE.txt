HasVat: true - если значение true то внутри какогото продукта в поле ставка НДС стоит какойто протцент ставки НДС может быть (0%, 6%, 12%) и после внутри каждого продукта появится новое значение подназваним "WithoutVat" | false - для обшего продукта если у каждого продукта поля ставка НДС "Без НДС" то для всего работает это значение и этоже обозначает что ставка было выброна как Без ндс

если поля HasVat - false то это поля не появится так как HasVat это обшая значение отвечает (har bitta mahsulot ichida QQS bor agar shu QQS yoq bolsa "Без НДС" bolsa bu umumiy aga ishlidi barchasi uchun bitta false boladi agar bitta mahsulot da QQS joyida "0%, 6%, 12%" turgan bolsa unda usha mahsulot uchun WthoutVat digan yangi joy qoshiladi JSON dan kegin JSON da HasVat digan joyi true boladi WithoutVat esa true boladi QQS bor bolgani uchun yoq bolsa false boladi)
WithoutVat: - для каждого документа внутри будет выходить если поля "HasVat: true", поля WithoutVat для кажого документа работает отдельно если у конкретного продукто поля "НДС будет выбран как Без НДС то его значение будет false - так как у него нету НДС" если у конкретного продукта поля НДС будет как (0%,6%,12% - то его поля будет как true так как унего есть ставка ндс)
