НЕОБХОДИМО РЕАЛИЗОВАТЬ
======================

1. ДОРАБОТКА UI — 4 часа
------------------------
В разделе создания документов вывести отдельные формы для следующих типов гибридной счет-фактуры:

    1.1. Гибридная счет-фактура (ФАРМ)
        * Способ применения лекарственного средства
        * Штрих-код товара (услуги)
        * Серия
        * Цена приобретения (базовая цена)
        * Торговая надбавка (наценка) в процентах

    1.2. Гибридная счет-фактура (Акциз)
        * Акцизный Налог — Ставка, сумма

    1.3. Гибридная счет-фактура
        * Штрих-код

2. РАЗРАБОТКА HTML-ШАБЛОНОВ — 2 часа
------------------------------------
Разработать отдельные HTML-шаблоны для:

    2.1. Гибридной счет-фактуры ФАРМ
        * Способ применения лекарственного средства
        * Штрих-код товара (услуги)
        * Серия
        * Цена приобретения (базовая цена)
        * Торговая надбавка (наценка) в процентах

    2.2. Гибридной счет-фактуры Акциз
        * Акцизный Налог — Ставка, сумма

3. ДОРАБОТКА API — 8 часов
--------------------------
Доработать API создания гибридных счет-фактур:

    * добавить поддержку отдельных типов документов «ФАРМ» и «Акциз»;
    * реализовать корректное формирование JSON для каждого типа документа;
    * обеспечить совместимость с текущими интеграциями.
