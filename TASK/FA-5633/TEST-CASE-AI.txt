TEST-CASE: Гибридная счет-фактура — типы «ФАРМ», «Акциз» и со штрих-кодом
==========================================================================

Предусловие для всех кейсов: пользователь авторизован, открыт раздел создания документов.
Типы документов: Гибридная счет-фактура (ФАРМ), Гибридная счет-фактура (Акциз), Гибридная счет-фактура (со штрих-кодом).
Примечание: обязательность полей и форматы значений уточнить по требованиям (Notion: Rouming Documents).

TC-01. Отображение типов гибридной счет-фактуры в разделе создания документов

  Ожидаемо:   Доступны отдельные пункты: «Гибридная счет-фактура (ФАРМ)», «Гибридная счет-фактура (Акциз)»,

  Результат:  у каждого есть своя поля и они открываютса отдельно все есть

TC-05. Наличие фарм-полей в таблице товаров
  Шаги:       1. Открыть форму ФАРМ, добавить товар.
  Ожидаемо:   Для товара доступны поля: Способ применения лекарственного средства, Штрих-код товара (услуги),
              Серия, Цена приобретения (базовая цена), Торговая надбавка (наценка) в процентах.
  Результат:  

TC-06. Поле «Способ применения лекарственного средства»
  Шаги:       1. Ввести текст (кириллица, латиница, цифры, спецсимволы).
              2. Сохранить.
  Ожидаемо:   Значение сохраняется без искажений; при превышении лимита длины — ограничение или ошибка валидации.
  Результат:  можна только выбрать то что есть нелзя ввести текст

есть все поля и они все обизательные для каждого товара и для каждого документа
