ПЕРЕШОЛ ОБРАТНА НА ЭТУ ЗОДАЧУ 13.04
====


ТТН: СОХРАНЕНИЕ И ПОВТОРНОЕ ИСПОЛЬЗОВАНИЕ АДРЕСОВ
=================================================

ОПИСАНИЕ ЗАДАЧИ
---------------
Для упрощения и ускорения процесса создания ТТН необходимо реализовать механизм сохранения и повторного использования адресов грузоотправителя и грузополучателя.

Пользователь должен иметь возможность сохранять часто используемые адреса организации и выбирать их из справочника при оформлении ТТН без необходимости повторного ввода данных.


=================================================
FRONTEND
=================================================

1. ДОРАБОТКА ИНТЕРФЕЙСА ТТН
---------------------------
В разделе заполнения адресов груза добавить две новые кнопки:

  * Мои адреса
  * Адреса партнера (кнопка должна быть в состоянии disabled, если не были введены данные грузополучателя)


2. ФУНКЦИОНАЛ «МОИ АДРЕСА»
--------------------------
При нажатии на кнопку «Мои адреса» должно открываться боковое меню (Drawer), содержащее список сохраненных адресов текущей организации.

Для каждого адреса необходимо отображать:

  * название/краткое описание адреса (при наличии);
  * область;
  * район;
  * махаллю;
  * улицу;
  * полный адрес.


3. ДОБАВЛЕНИЕ НОВОГО АДРЕСА
---------------------------
В боковом меню добавить кнопку:

  «Добавить новый адрес»

При нажатии должна открываться модальная форма создания адреса.


4. ФОРМА ДОБАВЛЕНИЯ АДРЕСА
--------------------------
Модальное окно должно содержать следующие поля:

  Поле      | Тип
  ----------+----------------
  Область   | DropDown List
  Район     | DropDown List
  Махалля   | DropDown List
  Адрес     | Текстовое поле
  Улица     | Текстовое поле


5. ОТОБРАЖЕНИЕ АДРЕСА НА КАРТЕ
------------------------------
В модальном окне необходимо добавить кнопку:

  «Показать на карте»

После заполнения обязательных полей система должна:

  * определить предполагаемое местоположение;
  * отобразить выбранный адрес на карте;
  * позволить пользователю проверить корректность адреса перед сохранением.

Дополнительно рекомендуется предусмотреть возможность уточнения геопозиции через карту.


6. СОХРАНЕНИЕ АДРЕСА
--------------------
После заполнения обязательных полей пользователь нажимает кнопку:

  «Сохранить»

Система должна:

  * выполнить валидацию данных;
  * сохранить адрес в справочнике организации;
  * отобразить новый адрес в списке «Мои адреса».


7. АВТОЗАПОЛНЕНИЕ АДРЕСА В ТТН
------------------------------
При выборе сохраненного адреса из списка:

  * поля адреса погрузки должны автоматически заполниться;
  * должны подставляться все сохраненные реквизиты адреса;
  * пользователь должен иметь возможность отредактировать данные вручную при необходимости.


8. ФУНКЦИОНАЛ «АДРЕСА ПАРТНЕРА»
-------------------------------
При нажатии на кнопку «Адреса партнера» должно открываться отдельное боковое меню со списком адресов контрагента.

Система должна:

  * получать адреса выбранного партнера;
  * отображать список сохраненных адресов;
  * позволять выбрать адрес для автоматического заполнения полей разгрузки.


9. ДОПОЛНИТЕЛЬНЫЕ ВОЗМОЖНОСТИ
-----------------------------
Для каждого сохраненного адреса предусмотреть:

  * редактирование;
  * удаление;
  * поиск по адресу;
  * сортировку по дате добавления;


=================================================
BACKEND
=================================================

Для работы с адресами новые API-методы создавать не требуется.
Необходимо использовать существующие методы API ГНК.


1. ПОЛУЧЕНИЕ СПИСКА АДРЕСОВ ОРГАНИЗАЦИИ
---------------------------------------
Для получения адресов грузоотправителя и грузополучателя использовать метод:

  /provider/api/{lang}/waybills-v2/utils/companies/{tinOrPinfl}

Метод используется для:

  * получения списка адресов организации;
  * отображения адресов в разделе «Мои адреса»;
  * отображения адресов партнера в разделе «Адреса партнера».


2. ДОБАВЛЕНИЕ НОВОГО АДРЕСА
---------------------------
Для создания нового адреса использовать метод:

  /provider/api/{lang}/waybills-v2/utils/companies/add-address

После успешного создания необходимо обновить список адресов в интерфейсе.


3. РЕДАКТИРОВАНИЕ АДРЕСА
------------------------
Для изменения существующего адреса использовать метод:

  /provider/api/{lang}/waybills-v2/utils/companies/update-address

После успешного обновления необходимо актуализировать данные в списке адресов.


4. УДАЛЕНИЕ АДРЕСА
------------------
Для удаления адреса использовать метод:

  /provider/api/{lang}/waybills-v2/utils/companies/delete-address

После успешного удаления адрес должен исчезнуть из списка без обновления страницы.


=================================================
API
=================================================

  * получение списка адресов организации;
  * создание адреса;
  * редактирование адреса;
  * удаление адреса;
  * получение адресов партнера.
