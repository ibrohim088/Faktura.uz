Key: FA-5871
Summary: Учитывать код филиала в preview отправителя и получателя для договора (роуминг)
Status: ON DEV TESTING
Type: Task
Assignee: Xamidullo Xudaykulov

=== DESCRIPTION ===
Для документов типа «Договор» (роуминг) preview отправителя и получателя сейчас строится без учёта кода филиала в подписываемом JSON.

Некоторые договоры от других операторов роуминга приходят с наименованием филиала, но без кода филиала. Налоговая проверяет наличие кода филиала и при его отсутствии показывает договор без наименования филиала. У нас такие договоры отображаются с наименованием филиала, то есть иначе, чем в налоговой.

h2. Необходимо реализовать

h3. Логика отображения preview для договора (роуминг)
 * Для документа типа «Договор» (роуминг) при построении preview отправителя и получателя проверять в подписываемом JSON наличие кода филиала по каждой из сторон.
 * Если код филиала есть, показывать наименование филиала, как сейчас.
 * Если кода филиала нет, не показывать наименование филиала, даже если оно передано в подписываемом JSON.
 * Проверять отправителя и получателя отдельно, независимо друг от друга.

h3. Область изменений
 * Изменения касаются только документов типа «Договор» (роуминг).
 * Отображение остальных типов документов не меняется.
 * Подписываемый JSON не меняется. Меняется только отображение в preview.

h2. Ожидаемый результат

Preview отправителя и получателя для договоров из роуминга совпадает с тем, как налоговая отображает данные о филиале: наименование филиала показывается только вместе с кодом филиала в подписываемом JSON.

h2. Критерии приёмки
 # Для договора (роуминг), где в подписываемом JSON есть и код, и наименование филиала отправителя, в preview отправителя показывается наименование филиала.
 # Для договора (роуминг), где в подписываемом JSON есть наименование филиала отправителя, но нет кода филиала, в preview отправителя наименование филиала не показывается.
 # Пункты 1 и 2 так же выполняются для получателя.
 # Отправитель и получатель проверяются независимо: если код филиала есть только у одной стороны, наименование филиала показывается только у этой стороны.
 # Отображение preview для других типов документов не изменилось.
 # Подписываемый JSON договора не изменяется.
