ТЕСТ-КЕЙСЫ: Preview договора (роуминг) — отображение наименования филиала по коду филиала
==========================================================================================

Суть изменения:
Для документа типа «Договор» (роуминг) в preview отправителя и получателя наименование филиала
показывается только если в подписываемом JSON есть код филиала соответствующей стороны.
Стороны проверяются независимо. Подписываемый JSON не меняется. Другие типы документов не меняются.

ОБЩИЕ ШАГИ (для всех кейсов)
1. Открыть в системе договор, пришедший из роуминга, с данными из предусловия.
2. Открыть preview (блоки отправителя и получателя).
3. Сверить поля филиала в подписываемом JSON с отображением в preview.
