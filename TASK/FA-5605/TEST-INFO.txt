ПРОБЛЕМА
-------------------------------------------------------------------------------
После отправки документа типа «Письмо НК», его прочтения получателем в роуминге и последующей синхронизации статусов в системе происходит некорректное обновление статуса документа.

Вместо статуса:
  * «Прочитано» (код 16)

документ получает статус:
  * «Заверен системой» (код 46)

Данный статус предназначен для документов дилеров мобильных операторов
и не должен использоваться для роуминговых документов типа «Письмо НК».


ТРЕБОВАНИЕ
-------------------------------------------------------------------------------
После отправки документа типа «Письмо НК», его прочтения получателем
в Faktura.uz статус документа для обоих сторон должен измениться,
а также необходимо отправить обратную связь роумингу о смене статуса. 


ВНУТРЕННИЙ ОБМЕН FAKTURA.UZ
-------------------------------------------------------------------------------
  1. Отправитель отправляет документ пользователю внутри Faktura.uz.
  2. Получатель открывает документ.
  3. Статус документа не изменяется автоматически.


ОЖИДАЕМЫЙ РЕЗУЛЬТАТ
-------------------------------------------------------------------------------
  * После открытия документа получателем статус должен автоматически
    измениться на:
        - «Прочитано» (код 16);

  * Статус должен обновиться для обеих сторон:
        - отправителя;
        - получателя.
