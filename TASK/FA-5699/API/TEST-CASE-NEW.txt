ТЕСТ-КЕЙСЫ: truck.model (API создания путевого листа)

ПРАВИЛО
  model передан -> берём его (кэш и soliq не используются)
  model пустой  -> берём из soliq (значение в БД не должно влиять)

В запросе меняем только: carrier.inn_or_pinfl, truck.reg_number, truck.model
Номер в API без пробелов (70G759DB), в БД с пробелами (70 G 759 DB).

----------------------------------------------------------------
ПЕРЕВОЗЧИК 30307932640029, номер 70G759DB  (в БД COBALT, в soliq CHERY EQ7...)

1) model = ""       -> ожидаем CHERY EQ7... (из soliq). Если COBALT - FAIL
   Результат:
   Статус: PASS / FAIL

2) model = "MALIBU" -> ожидаем MALIBU
   Результат:
   Статус: PASS / FAIL
