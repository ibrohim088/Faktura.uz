Необходимо реализовать в пользовательском интерфейсе возможность синхронизации роуминговых документов с использованием метода: GET /Api/Patch/SyncRoamingDocument/{UID} 
Реализовать новый функционал в разделе: https://app.faktura.uz/ru/synchronization/index
Добавить новую вкладку: «Синхронизация документов по ID»

Метод принимает следующие параметры:
	INN -> ИНН организации.
	По умолчанию необходимо автоматически подставлять ИНН организации текущего пользователя.

ContractorType:
	Отправитель = 0,
	Получатель = 1,
	Система = 2,
	Доверенный лицо = 3,
	Комитент = 4

ModelType:
        Счет фактура = 0,
        Доверенность = 1,
        Акт = 2,
        ТТН = 3,
        Акт сверки = 4,
        Договор = 5

 
1. Одиночная синхронизация: Добавить форму для синхронизации одного документа.

Поля формы:
	UID документа;
	ИНН организации (по умолчанию заполнен);
	ContractorType (выпадающий список);
	ModelType (выпадающий список).
	После нажатия кнопки Синхронизировать должен выполняться вызов метода: GET /Api/Patch/SyncRoamingDocument/{UID} с выбранными параметрами.

2. Массовая синхронизация: Добавить возможность массовой синхронизации документов.

Пользователь должен иметь возможность:
	вставить список UID вручную;
	вводить несколько UID построчно;
	запускать синхронизацию всех документов одной операцией.
