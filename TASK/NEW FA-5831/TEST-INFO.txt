В панели администратора в разделе «Отчёт → Отчёт по организациям» необходимо добавить новый тип отчёта, 
позволяющий анализировать регистрацию организаций и использование ими услуг Faktura.uz за выбранный период.

Отчёт должен формироваться в формате Excel и содержать три отдельных листа с данными о зарегистрированных организациях, 
организациях, воспользовавшихся услугами после регистрации, и организациях, которые не использовали услуги после регистрации.

Необходимо реализовать:

1. Добавить новый тип отчёта:
    В разделе «Отчёт по организациям» добавить возможность формирования отчёта по новым зарегистрированным организациям за выбранный период.
    Предусмотреть выбор начальной и конечной даты и кнопку формирования отчёта.

2. Сформировать Excel-отчёт с тремя листами
    Лист 1 — «Новые организации»:
        Список организаций, зарегистрированных в выбранном периоде.
        Дата регистрации организации.
        Основные идентификационные данные организации: наименование, ИНН и другие доступные реквизиты.

    Лист 2 — «Использовали услуги»:
        Список организаций из числа зарегистрированных в выбранном периоде, которые воспользовались услугами системы после регистрации.
        Дата регистрации.
        Дата первого использования услуги, если доступна.
        Основные идентификационные данные организации.

    Лист 3 — «Не использовали услуги»:
        Список организаций, зарегистрированных в выбранном периоде, которые после регистрации не воспользовались услугами системы.
        Дата регистрации.
        Основные идентификационные данные организации.

3. Реализовать логику определения использования услуг:
    Определять факт использования услуг на основании имеющихся данных системы.
    Разделять организации на две группы: использовавшие услуги после регистрации и не использовавшие услуги.
    Исключить дублирование организаций в рамках одной категории.
    Учитывать только организации, зарегистрированные в выбранном периоде.

4. Обеспечить корректное формирование отчёта:
    Формировать все три листа в одном Excel-файле.
    Предусмотреть корректную обработку пустых результатов.
    Обеспечить соответствие данных выбранному периоду регистрации.
    Ожидаемый результат

    В разделе «Админ-панель → Отчёт → Отчёт по организациям» доступен новый тип отчёта. 
    После выбора периода и формирования отчёта пользователь получает Excel-файл с тремя листами:

    Новые организации — все организации, зарегистрированные за выбранный период.
    Использовали услуги — зарегистрированные организации, которые воспользовались услугами после регистрации.
    Не использовали услуги — зарегистрированные организации, которые не воспользовались услугами после регистрации.
