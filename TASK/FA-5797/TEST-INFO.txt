https://jira.faktura.uz/browse/FA-5797 - Изменить лимит количества знаков после запятой для поля «Количество» в подписываемом JSON ЭХФ


Task Description:

    В роуминговой системе было внесено изменение для поля «Количество (сони)» в ЭХФ: теперь значение может содержать до 10 знаков после запятой в соответствии с п. 15 приложения №2 к Постановлению Кабинета Министров №489 от 14.08.2020.
    Необходимо внести соответствующие изменения в формирование подписываемого JSON ЭХФ.

    Требования:
        1. Изменить допустимое количество знаков после запятой для поля «Количество (сони)» — до 10 знаков.
        2. Обеспечить корректное формирование значения в подписываемом JSON.
        3. При передаче ЭХФ в роуминг должно корректно выполняться вычисление:
    
    Количество × Цена = Сумма поставки:
        1. Не допускать некорректного округления значения Количество, которое может привести к расхождению итоговой суммы.
        2. Проверить обратную совместимость с ЭХФ, где количество содержит меньше 10 знаков после запятой.


UI, API, EXCEL - надо проверить
