### Поподаем в Home

После того как мы включили чекбокс внутри "Панель Администратора", мы идём в "Главное" → "Настройки" → "Роли", находим нужного пользователя, нажимаем на кнопку "Редактировать", открываем список "Документ" — тут тоже есть чекбокс, но уже внутри самой компании.

**Короткое Информация о путях**

```
"Главное" --> "Настройки" --> "Роли" ==> "Редактировать" ==> "Документ" 
```

### Для создания нового типа договора заходим в "Договор" — там появятся поля "Договор аренды (юр. лицо)" и "Договор аренды (физ. лицо)".

Заходим в "Договор аренды (юр. лицо)" — заполняем поля дат как обычные даты, остальные поля как обычно.

```Все обязательные поля

-- Стороны и реквизиты договора
    Юридическое лицо (Арендодатель)
    Филиал
    Номер договора
    Дата договора
    Город, район
    Валюта договора
    Номер доверенности
    Дата доверенности

-- Объект аренды
    Тип объекта 1
    Площадь объекта 1 (кв.м.)
    Адрес объекта
    Правоустанавливающие документы

-- Срок аренды
    Дата начала аренды
    Дата окончания аренды
    Месяц первой оплаты
    Срок первой оплаты

---- "Стоимость аренды" — необязательное поле, но если его не заполнить, то сумма (которая обязательна) не рассчитается, и документ не создастся.
    Адрес объекта
    Тип арендуемых площадей
    Площадь (кв.м.)
    Расчетный период
    Стоимость в месяц с НДС
    Стоимость договора с НДС

-- Протокол соглашения о договорной цене
    Период с
    Период по
    Сумма - связона с Итог если он будет пустым то Документ он не создастся 
    Сумма прописью - Заполняется автоматически по сумме

```

### Если не заполнить "Стоимость аренды", выйдет ошибка: «Заполните хотя бы одну строку в разделе "Стоимость аренды"»

### Если не заполнить какое-то поле внутри файла, документ не создастся — выйдет ошибка. Если хотя бы одно из обязательных полей не заполнено, появится ошибка о том, что нужно заполнить все обязательные поля.

### Если не заполнить "Стоимость договора с НДФЛ" внутри раздела "Стоимость аренды", выйдет ошибка: «Заполните хотя бы одну строку в разделе "Стоимость аренды"».
